This is a simple text-based Trick or Treat program. It asks for user input (y/n) and outputs either a trick or a treat. It also keeps a running total of what items are in your bag

### Input
 - 'y' to knock on a door
 - 'n' to end the game

 ### Output
 - A randomly chosen trick or treat each time you knock on a door
 - A list of everything in your bag
 - The total number of treats and the total number of tricks

 ## Run Instructions

 ### Requirements
 - Python

 ### Steps
 1. Clone the repository:
 ```
    git clone https://github.com/marcmalaspino/IS450-Assignment7
    cd IS450-Assignment7
```

2. Run the program:
```
    python myProgram.py
```

3. Follow the prompts in the terminal
